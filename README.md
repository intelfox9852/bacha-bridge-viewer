# 八坼大桥三维查看器

WebGPU优先，兼容WebGL2；实体＋轮廓默认显示，四边形线框保留原始面边界。支持单元点选高亮、属性与图纸依据、主桥按63个施工块件、引桥按7联及护栏按8联选择、聚焦、Esc取消、距离测量、钢束透视、菜单隐藏、墩台编号和上部结构剖面。

总布置以SII-4C为准：18×20＋(60＋100＋60)＋14×20m，西端恢复-5号台原位K0+527.650。主桥上部构造采用SII-7A，引桥采用SII-48C/49B，32跨共544块空心板，板高90cm、圆孔62.5cm。主桥双室箱梁包含变厚腹板、梗腋、横梁人孔与80cm底板检修孔。护栏采用SII-65C/66C，盖梁采用SII-56C/57C。

纵向预应力按SII-8/9/10重建292条钢束，按束号分为腹板束W系列42条、顶板束D/BH/ZH系列174条、底板束B/Z系列76条，各自可独立显隐。20条预留孔道另层显示；B2/B3另4条线与材料表数量冲突，默认隐藏待核对。横向预应力仍为示意。小孔、钢筋、部分支承和附属细部未展开；详见“建模依据与待核验项.txt”。模型用于浏览与深化，不用于施工放样或精确算量。

新增2184处支座垫石，支持单独点选及主桥/引桥垫石查看视图。主墩垫石采用SII-39的200×200×14.5cm轮廓；引桥高2cm、平面暂按46×43cm调平钢板投影，过渡墩主桥垫石横向暂取100cm。未确认的平面尺寸及逐墩调坡高度在“支座垫石参数.json”中标为待核对。

地形采用“八坼大桥地形图.dwg”，按SI-5路线逐桩坐标等比例配准，并以SII-6墩台中心复核。三维陆域由262个经文字标高和测点符号Z交叉核对的原图测点构建Delaunay TIN，高程0.100～4.145m，测点间线性插值，无竖向夸大。“显示三维地形”和“显示平面地形”是独立模式按钮；支持测绘/高程着色、测点、近景、全图与透明度，剖面/垫石视图自动隐藏地形。河床按SII-1/SII-4C设计高程-2.80m建模，与现状岸线顺接的边坡及沿河外延为示意。蓝色水体按最高通航参考水位+2.20m建立，非实时水位；支持河床、水体独立显隐和水体透明度。三维模式将河道的0m参考底图镂空，避免遮挡水下河床；平面模式在0m参考面显示蓝色河道。未作漫滩、冲淤或水动力计算。陆域凸包外及超过120m的空白区不外推，河岸加密点为同岸测点插值。西端缓和曲线与直线桥梁模型仍有约0.5m差异。详见“地形底图配准.json”“三维地形说明.json”“地形高程点.csv”及“河床与水体建模依据.json”。

新增独立Cesium周边大场景（cesium.html），可从细部查看器进入。CesiumJS 1.147.0、Proj4js 2.22.0和模型资源均自托管；在线卫星影像采用Esri公开服务，道路地图采用OpenStreetMap，环境地形采用Tilezen Terrain Tiles公开DEM并融合工程局部TIN/设计河床，带各数据源署名。内置Natural Earth低精度底图作后备。支持桥位、周边5公里、区域20公里、地球、主桥钢束视角，图层显隐和水体透明度。大场景三类钢束按需加载，支持桥梁透视；构件点选和工程测量保留在细部查看器。

用户确认暂无当地转换参数，采用北京54三度带120E中央子午线及通用三参数近似定位，未作当地控制点校核。支持东西/南北/高程/方向微调，仅保存到当前浏览器；桥梁与工程地形共用定位，不改变内部尺寸。85高程与椭球高转换未确定，环境DEM与工程测绘年代、精度可能不同。详见“大场景定位与数据说明.json”。

倾斜摄影加载：支持3D Tiles服务地址、本地完整目录（无需上传），保留嵌套入口、子瓦片、glTF缓冲和贴图的相对路径。支持显隐、定位、移除、加载精度及独立位置/高程偏移。原始OSGB需先依据坐标系和原点转换为3D Tiles；没有地球定位的数据会提示补充坐标，不会任意放到桥位。默认没有倾斜摄影数据，需用户选择目录或提供服务地址。详见“倾斜摄影加载说明.txt”。

当前场地采用建筑白模。三维地形和平面底图裁到测点插值覆盖范围。道路经过的3处池塘改为陆地，其余5处保留蓝色水面。西侧道路延长线及距桥梁边缘不足5米的建筑已清理，5米为场景展示取值。地物清单和清理范围见“地物清单.csv”及“地物调整记录.json”。

细部模型按同类及钢束类别合批，保留单元索引；现代浏览器优先下载gzip模型，旧浏览器回退JSON。工程查看器及Cesium运行库、模型自托管；周边在线地图/DEM需要联网。GitHub Pages从main分支根目录发布。

13号墩和16号墩附近的南侧人行梯道按SII-4C及SII-75A建模。每处长59.7米、宽3.5米，含六段踏步、平台、栏杆、墩柱和桩基。桥面衔接与栏杆细部简化情况见“梯道建模依据.json”。
